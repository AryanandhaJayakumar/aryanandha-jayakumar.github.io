PROJECTS

Online
Photographer
Booking: CLICKSY
View Project

CLICKSY ,a web platform that makes it easier for people to find and book photographers in one place. Users can browse photographer profiles and portfolios, compare packages, check availability, choose a suitable service, and complete their booking online. Photographers can maintain their profiles, showcase their work, manage packages and pricing, and keep track of booking requests. The platform also includes user authentication, reviews, ratings, and payment handling.

This project was developed using React.js, JavaScript, HTML, and CSS for the frontend, with Node.js and Express.js handling the backend services. MongoDB was used to store user, photographer, portfolio, package, booking, and review details. REST APIs connected the frontend with the backend, while JWT and bcrypt were used for login security. I used Git and GitHub for version control, Postman for API testing, and VS Code throughout the development process.

Interactive
Quiz
Application
View Project

QUIZMASTER, an interactive web-based quiz application designed to make learning more engaging and enjoyable. Users can create an account, log in, select different quiz categories, and attend timed quizzes. The application provides instant answer explanations, progress tracking, performance levels, achievements, and quiz statistics. Users can also retake quizzes to improve their scores and track their overall performance.

This project was developed using HTML5, CSS3, and JavaScript. HTML5 was used to structure the application, while CSS3 was used for the responsive design, animations, cards, buttons, and modern dashboard interface. JavaScript handles the quiz logic, timer, category selection, answer validation, score calculation, instant explanations, achievements, performance levels, and progress tracking. Browser LocalStorage was used to store user information, login status, quiz statistics, scores, and achievements. The project was developed and tested using VS Code and managed with Git and GitHub.

Weather
Forecasting
System
View Project

WEATHER FORCASTING APPLICATION that uses past weather records to estimate upcoming atmospheric conditions. The application works with factors such as temperature, humidity, wind speed, and atmospheric pressure, allowing the system to identify relationships in the data and produce short-term predictions. I worked on preparing the weather data, handling missing or inconsistent values, selecting useful parameters, and training the prediction model.

This project was built mainly with Python, using Pandas and NumPy for data processing and Scikit-learn for machine learning. Flask was used to connect the prediction model with the web application, while HTML, CSS, and JavaScript were used for the user interface. Jupyter Notebook and VS Code were used during development and model testing, with Git and GitHub for maintaining the project code.
